### 🔧 Module 0: Setup & Python Essentials (Days 1-3)
**What You'll Build:** Your first Python program

- Your first Hello AI program

### 🌐 Module 1: Web & Data Fundamentals (Days 4-7)
**What You'll Build:** Your first API interaction

What you learn:
- Reading/writing files
- JSON (the language of APIs)
- Making API calls
- FastAPI basics

Mini Project: Get random jokes from the internet!
Time: 4 hours | Difficulty: Beginner → Intermediate

---

### 🧠 Module 2: LLM Fundamentals & Prompt Engineering (Days 8-14)
**What You'll Build:** Your first ChatGPT-powered app

What you learn:
- How ChatGPT actually works
- Getting API keys (OpenAI, Google)
- Making LLM API calls
- Prompt Engineering (#1 skill for GenAI jobs!)
- System messages & personas
- Structured JSON responses

Mini Project: Build a prompt library
Time: 7 hours | Difficulty: Intermediate
**MOST IMPORTANT MODULE FOR JOB INTERVIEWS!**

---

### 💬 Module 3: LLM Application Development (Days 15-20)
**What You'll Build:** Multi-turn AI chatbot + CLI Assistant

What you learn:
- Maintaining conversation history
- Streaming responses (real-time output)
- Error handling & retries
- Function calling (let AI use tools)
- Combine FastAPI + LLM

Portfolio Project 1: Command-line AI Assistant
Time: 6 hours | Difficulty: Intermediate

---

### 📖 Module 4: RAG - Retrieval-Augmented Generation (Days 21-29)
**What You'll Build:** Document Q&A Bot

What you learn:
- Text embeddings
- Vector databases
- Document loading & chunking
- RAG pipeline (retrieval + generation)
- Adding citations (showing sources)
- Evaluating RAG performance

Portfolio Project 2: Document Q&A Bot
Time: 9 hours | Difficulty: Intermediate → Advanced
RAG is how ChatGPT handles custom knowledge!

---

### 🤖 Module 5: AI Agents & Workflows (Days 30-35)
**What You'll Build:** Research Assistant using multiple tools

What you learn:
- What are AI agents (beyond chatbots)
- Defining tools & capabilities
- Multi-tool decision making
- Agent memory (short & long-term)
- Workflow automation

Portfolio Project 3: Research Assistant Agent
Time: 6 hours | Difficulty: Advanced
Agents are the future of AI automation!

---

### 🎯 Module 6: Fine-tuning & Model Adaptation (Days 36-40)
**What You'll Build:** Custom AI models trained on YOUR data

What you learn:
- Fine-tuning basics
- Preparing training data
- Fine-tuning process
- LoRA (efficient fine-tuning)
- When to use: Prompting vs RAG vs Fine-tuning

Time: 5 hours | Difficulty: Advanced
The skill that separates pros from beginners!

### 🚀 Module 7: Deployment & Production (Days 41-45)
