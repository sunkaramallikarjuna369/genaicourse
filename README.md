# GenAI Course for BTech Freshers - 75 Hours (Detailed Version)

A comprehensive 75-day Generative AI course designed for BTech freshers with no prior experience. Each day is 1 hour of focused learning, combining theory with hands-on practice to make you placement-ready.

**This is the DETAILED version** - same topics as the 50-day fast-track but with more in-depth explanations, additional exercises, and extra practice time.

## Course Overview

**Duration:** 75 Days (1 hour per day = 75 hours total)  
**Target Audience:** BTech freshers with no prior AI/ML knowledge  
**Goal:** Make students job-ready for GenAI application developer roles  
**Prerequisites:** Basic computer skills, willingness to learn

## Difference from 50-Day Fast-Track

| Aspect | 50-Day Fast-Track | 75-Day Detailed |
|--------|-------------------|-----------------|
| Pace | Quick overview | In-depth coverage |
| Exercises | Basic exercises | Multiple exercises per topic |
| Theory | Essential concepts | Detailed explanations |
| Projects | 4 mini + 1 capstone | 6 mini + 2 capstone |
| Practice | Limited | Extended practice days |
| Interview Prep | 1 day | 5 days |

## What You'll Learn

By the end of this course, you will be able to:
- Write Python code for AI applications confidently
- Deeply understand how Large Language Models (LLMs) work
- Master advanced prompt engineering techniques
- Build production-ready RAG applications
- Create sophisticated AI agents and workflows
- Deploy and monitor GenAI applications
- Excel in technical interviews

## Tools & Technologies

- **Language:** Python 3.10+
- **IDE:** VS Code / Google Colab
- **LLM APIs:** OpenAI, Google Gemini, Groq, Anthropic Claude
- **Frameworks:** LangChain, LlamaIndex, FastAPI, Streamlit
- **Vector DB:** ChromaDB, Pinecone, Weaviate
- **Deployment:** Docker, Kubernetes basics, Render/Railway/Fly.io

## How to Use This Course

1. Follow the days in order - each day builds on previous knowledge
2. Complete ALL hands-on exercises - practice is key
3. Don't skip the review days - they reinforce learning
4. Build the mini-projects at the end of each module
5. Push your code to GitHub to build your portfolio
6. Take notes and create your own reference guide

## Daily Structure

Each day follows this pattern:
- **Concept (20 min):** Detailed theory and explanation
- **Hands-on (30 min):** Multiple coding exercises
- **Recap (10 min):** Summary, quiz, and preview of next day
