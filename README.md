# GenAI Course for BTech Freshers - 50 Days to Job Ready

A comprehensive 50-day Generative AI course designed for BTech freshers with no prior experience. Each day is 1 hour of focused learning, combining theory with hands-on practice to make you placement-ready.

## Course Overview

**Duration:** 50 Days (1 hour per day = 50 hours total)  
**Target Audience:** BTech freshers with no prior AI/ML knowledge  
**Goal:** Make students job-ready for GenAI application developer roles  
**Prerequisites:** Basic computer skills, willingness to learn

## What You'll Learn

By the end of this course, you will be able to:
- Write Python code for AI applications
- Understand how Large Language Models (LLMs) work
- Master prompt engineering techniques
- Build RAG (Retrieval-Augmented Generation) applications
- Create AI agents and workflows
- Deploy GenAI applications to production
- Prepare for technical interviews

## Course Structure

| Module | Days | Topics |
|--------|------|--------|
| Module 0 | Days 1-3 | Setup & Python Essentials |
| Module 1 | Days 4-7 | Web & Data Fundamentals |
| Module 2 | Days 8-14 | LLM Fundamentals & Prompt Engineering |
| Module 3 | Days 15-20 | LLM Application Development |
| Module 4 | Days 21-29 | RAG (Retrieval-Augmented Generation) |
| Module 5 | Days 30-35 | AI Agents & Workflows |
| Module 6 | Days 36-40 | Fine-tuning & Model Adaptation |
| Module 7 | Days 41-45 | Deployment & Production |
| Module 8 | Days 46-50 | Capstone Project & Interview Prep |

## Projects You'll Build

1. **Prompt Engineering Lab** - A collection of optimized prompts for various tasks
2. **LLM-Powered API Service** - FastAPI backend with streaming responses
3. **RAG Chatbot** - Document-based Q&A system with citations
4. **AI Agent** - Multi-tool assistant for automated tasks
5. **Capstone Project** - Complete deployed GenAI application

## Tools & Technologies

- **Language:** Python 3.10+
- **IDE:** VS Code / Google Colab
- **LLM APIs:** OpenAI, Google Gemini, Groq
- **Frameworks:** LangChain, FastAPI, Streamlit
- **Vector DB:** ChromaDB, Pinecone
- **Deployment:** Docker, Render/Railway

## How to Use This Course

1. Follow the days in order - each day builds on previous knowledge
2. Complete all hands-on exercises - don't just read
3. Build the mini-projects at the end of each module
4. Push your code to GitHub to build your portfolio
5. Review and practice before moving to the next module

## Daily Structure

Each day follows this pattern:
- **Concept (15 min):** Theory and explanation
- **Hands-on (35 min):** Coding exercises and practice
- **Recap (10 min):** Summary and quiz questions
